# Security and privacy

[English version](SECURITY.md)

Playlog предназначен для личного использования на взломанной PS5. Он не
подключается к PSN и не отправляет данные во внешние сервисы.

## Важные ограничения релиза

- HTTP-сервер использует обычный HTTP без шифрования.
- LAN-view раскрывает историю игр и время сессий любому клиенту, которому
  доступен порт консоли.
- Не публикуйте порт `12888` в интернет и не пробрасывайте его через роутер.
- Перед тестированием на основной статистике сделайте backup через dashboard.
- Не запускайте два экземпляра Playlog и не оставляйте одновременно
  включённые etaHEN и ShadowMount+/PLK автозапуски.

## Сообщения об уязвимостях

Не публикуйте детали потенциальной уязвимости в открытом issue до выпуска
исправления. Временно используйте private GitHub Security Advisory или
обратный канал сопровождающего проекта и приложите:

- версию релиза;
- прошивку и способ автозапуска;
- минимальные шаги воспроизведения;
- логи без IP, имён профилей и пользовательской истории.
