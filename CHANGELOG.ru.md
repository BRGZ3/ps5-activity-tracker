# Changelog

[English version](CHANGELOG.md)

## 1.1.0 — 2026-08-14

- объединены отслеживание через `SceShellCoreUtilAppFocus` и старый fallback
  `/dev/klog`, чтобы поддержать разные форматы событий прошивок;
- добавлены локальные обложки игр из метаданных консоли без Интернета;
- окно первоначальной настройки больше не открывается при каждом входе, если
  прошивка не определилась автоматически: значение `unknown` можно сохранить;
- offline update обновляет все найденные копии runtime и не помечает carrier
  применённым, пока рабочая точка запуска не записана;
- перед каждым offline update автоматически создаётся backup статистики.

## 1.0.1-beta.2 — 2026-08-14

- переходы между игрой и Home теперь отслеживаются через
  `SceShellCoreUtilAppFocus`;
- старый focus-парсер `/dev/klog` сохранён как fallback для ранних прошивок;
- исправляется нулевой учёт сессий, обнаруженный на firmware 11.60, где
  отсутствует строка `FG App was changed`;
- одинаковые lifecycle-переходы из двух источников не дублируются.

## 1.0.1-beta.1 — 2026-08-12

- Playlog больше не создаёт `/data/ps5_autoloader/autoload.txt`, если файла не было;
- пустые конфигурации, комментарии и директивы остаются без изменений;
- Playlog добавляется только в уже существующую цепочку с другими payload;
- если Playlog уже прописан, выбранная пользователем позиция сохраняется;
- если Playlog является единственным payload, выводится предупреждение;
- интерфейс сообщает, когда требуется ручная настройка Payload Manager/autoload.

## 1.0.0 — 2026-08-06

Первый публичный релиз Playlog / PS5 Activity Tracker.

Включает:

- сбор активности PS4 (`CUSA...`) и PS5 (`PPSA...`) игр;
- активное время, паузы, игровые сессии и календарные периоды;
- best-effort определение названий игр;
- отметку прохождения с возможностью отмены;
- локальный dashboard с RU/EN и LAN read-only просмотром;
- backup/restore статистики и offline carrier-обновления;
- один raw ELF для etaHEN и ShadowMount+/PLK в проверенных аппаратных сценариях.

Это полноценный релиз v1.0 с известными эксплуатационными ограничениями.
Они перечислены в `KNOWN_LIMITATIONS.ru.md`.
